# DECISIONS.md

## 초기 의사결정

| 결정 | 이유 | 상태 |
|---|---|---|
| 데모 v1 출력 형식은 JSON으로 한다. | AI 분석, 시각화, 저장, 비교가 쉬운 구조화 데이터가 필요하다. | 결정 |
| 데모 UI는 Streamlit을 사용한다. | 빠르게 업로드 UI와 JSON 확인 화면을 만들 수 있다. | 결정 |
| 주 언어는 Python으로 한다. | OpenCV, YOLO, 데이터 처리 생태계와 잘 맞는다. | 결정 |
| 객체 검출은 추후 Ultralytics YOLO 기반으로 연결한다. | 초기에는 구조 검증이 우선이며, YOLO는 교체 가능한 detector 모듈 뒤에 둔다. | 결정 |
| 3D 좌표는 정밀 복원이 아니라 영상 기반 추정값이다. | 단일 블랙박스 영상만으로 실제 깊이를 정확히 알 수 없기 때문이다. | 결정 |
| z 좌표는 초기에는 도로면 기준 0.0으로 둔다. | 데모 v1은 도로 위 객체 중심이며 고도 복원을 다루지 않는다. | 결정 |
| 모든 위치 추정값에는 confidence와 range를 포함한다. | 추정값의 불확실성을 JSON 소비자가 함께 판단해야 한다. | 결정 |
| 공개 저장소에는 캐시, 로컬 데이터, 비밀 설정 파일을 커밋하지 않는다. | 블랙박스 영상과 로컬 환경 정보가 GitHub에 올라가지 않도록 해야 한다. | 결정 |
| AGENTS.md는 공개 가능한 프로젝트 작업 규칙 중심으로 유지한다. | 내부 실행 세부사항보다 협업에 필요한 규칙을 남기는 편이 안전하다. | 결정 |
| v1.1은 실제 YOLO 전 단계로 업로드 영상 기반 더미 분석을 연결한다. | 영상 저장, 프레임 추출, JSON 저장 흐름을 먼저 안정화하면 추후 detector만 교체하기 쉽다. | 결정 |
| v1.1은 첫 번째 샘플 프레임 기준 Scene Vector JSON을 저장한다. | 프레임 시퀀스 분석은 추적과 움직임 벡터 설계가 필요하므로 다음 단계로 분리한다. | 결정 |
| v1.2는 데모용 실제 객체 검출 백엔드로 Ultralytics YOLO를 도입한다. | 빠르게 실제 bbox와 class를 얻어 Scene Vector 변환 흐름을 검증할 수 있다. | 결정 |
| YOLO는 장기 핵심 구조가 아니라 detector backend 중 하나로 둔다. | 이후 segmentation, depth, tracking, vision-language 백엔드를 추가할 여지를 유지해야 한다. | 결정 |
| v1.3은 추출된 모든 샘플 프레임에 detector를 적용한다. | 첫 프레임만 분석하면 영상 시퀀스 기반 Scene Vector 확장성을 확인하기 어렵다. | 결정 |
| v1.3은 슬라이더로 샘플 프레임을 넘겨보는 UI를 사용한다. | 실시간 재생 전 단계에서 프레임별 결과를 안정적으로 검수할 수 있다. | 결정 |
| v1.3은 프레임별 결과 배열을 `scene_vectors.json`으로 저장한다. | 단일 `scene_vector.json`과 구분해 시퀀스 분석 결과를 보존해야 한다. | 결정 |
| v1.3에서는 객체 추적과 실제 움직임 벡터 추정을 아직 하지 않는다. | 프레임별 detection 안정화 이후 track ID 연속성과 속도 추정을 별도 단계로 다루는 편이 안전하다. | 결정 |
| v1.4는 야간 전조등/고휘도 후보를 별도 detection source로 보존한다. | 정면 차량이 형상보다 빛으로 보이는 야간 장면에서 YOLO 단독 검출 누락을 줄여야 한다. | 결정 |
| v1.4는 도로 ROI 기반 강한 필터링을 적용하지 않는다. | 검증용 블랙박스 영상이 적은 상태에서 도로 위치 규칙을 강하게 넣으면 편향과 오탐 제거 실패가 커질 수 있다. | 결정 |
| v1.4는 이전 샘플 프레임의 고휘도 후보와 이어지는 경우 confidence를 보강한다. | 실제 영상 프레임에 가까운 샘플링이 될수록 앞뒤 프레임 비교가 누락 방지 근거로 작동할 수 있다. | 결정 |
| 전조등 후보는 확정 객체가 아니라 `is_candidate`와 `detection_reason`을 함께 기록한다. | 차량이라고 단정하지 않으면서도 위험 가능성이 있는 unknown 객체를 Scene Vector에 남기기 위해서다. | 결정 |
